# MindCare – AI Mental Health & Emotion Analysis Web App

A responsive web application designed to provide real-time mental wellness insights by combining live facial emotion detection with an interactive self-assessment module.

🔗 **Live Demo:** [https://sankhasubhrabarik92-a11y.github.io/mindcare/](https://sankhasubhrabarik92-a11y.github.io/mindcare/)

## Features
- **Live Face Emotion AI:** Uses the webcam to detect facial expressions in real time and displays live emotion distribution percentages (Happy, Calm, Stressed, Sad, Angry, Neutral).
- **Interactive Self-Assessment:** Slider-based questionnaire evaluating daily energy levels, overall mood, and ability to focus.
- **Results Dashboard:** Combines facial emotion distribution and assessment category scores to generate personalized wellness recommendations.

## Tech Stack
- HTML5, CSS3, JavaScript
- GitHub Pages (Deployment)
